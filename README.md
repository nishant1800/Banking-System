# 🏦 Banking System Analysis

## 📌 Project Overview

This project focuses on analyzing banking customer data to identify important business insights and customer trends.

The project uses **Python, Pandas, Matplotlib, Seaborn, and Power BI** for data analysis, visualization, and dashboard creation.

The analysis helps understand customer demographics, account information, financial behavior, and other important banking-related patterns.

---

## 🎯 Objectives

* Analyze banking customer data
* Perform data cleaning and preprocessing
* Explore customer demographics and financial information
* Identify important patterns and trends
* Create meaningful data visualizations
* Build an interactive Power BI dashboard
* Generate insights that can support business decisions

---

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/nishant1800/Banking-System.git
```

### 2. Navigate to the Project

```bash
cd Banking-System
```

### 3. Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Open the Jupyter Notebook

```bash
jupyter notebook
```

Then open:

```text
Banking.ipynb
```

### 5. Power BI Dashboard

Open:

```text
Banking_Dashboard.pbix
```

using **Microsoft Power BI Desktop**.
